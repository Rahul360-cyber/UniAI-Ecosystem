POLITECNICO DI TORINO LOGO
-------------------------
The university states that use of its official logo requires authorization.
This patch therefore includes an ORIGINAL campus-style background, not the logo.
If you already have permission to use the official logo, put the authorized PNG
at assets/polito_logo.png then enable "Show authorized university logo" in
Customize your view on the sidebar. The logo file is gitignored by default.
Use of a logo is not an endorsement; this is an unofficial student prototype.
